# 🎓 SIT Placement Portal (MERN Stack)

A comprehensive Placement Management System specifically tailored for **Sethu Institute of Technology**. This portal bridges the gap between the placement cell and students through automation and AI.

## 🌟 Key Highlights
- **Real-time Notifications:** Automated email alerts sent to students via NodeMailer whenever a new drive is published.
- **AI Career Assistant:** Integrated AI logic to provide instant career roadmaps and placement guidance.
- **Admin Dashboard:** Secure dashboard for Monica C (Admin) to manage drives, recruiters, and achievers.
- **Cloud Integration:** Scalable image handling using Cloudinary for achiever profiles.

## 🛠 Tech Stack
- **Frontend:** React.js, Tailwind CSS, Lucide Icons
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (SIT Database Schema)
- **Email:** NodeMailer with custom SMTP
